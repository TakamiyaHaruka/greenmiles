# BMad Method artifacts

This folder holds the implementation-side artifacts produced while building
GreenMiles with **BMad Method v6.7.1** and AI agents — the per-story paper
trail of an agent-driven development process.

Planning artifacts (product brief, PRD, architecture, UX spec, epics) were
produced in the same workflow but are not part of the repository; the
narrative recap of that phase, in Chinese, lives in
[`../zh-CN/项目全记录.md`](../zh-CN/项目全记录.md).

Docs here are mostly in Chinese.

```
implementation-artifacts/
├── 1-x … 4-x             # per-story implementation notes (4 epics)
├── project-progress.md   # story-by-story progress
└── sprint-status.yaml    # machine-readable sprint state
```

Suggested reading: start with `implementation-artifacts/project-progress.md`,
then open the per-story notes for whichever part of the app interests you.
