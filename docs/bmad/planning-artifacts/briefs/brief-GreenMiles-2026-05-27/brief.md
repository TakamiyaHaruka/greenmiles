# GreenMiles — 航司绿色里程生态商城

> 让飞行碳足迹可见，让闲置里程变绿。

---

## 一句话定位

GreenMiles 是一个面向航空会员的绿色里程生态商城：旅客输入航班信息即可看到本次飞行的碳排放量，并用里程兑换环保商品与碳抵消服务，实现"飞得越多，绿得越深"的正向循环。

---

## 我们解决什么问题？

一位常旅客每年飞行 20+ 次，累积了大量零碎里程——兑换机票门槛太高，兑换小礼品又觉得没意思。与此同时，旅客越来越关注自己的碳足迹，但缺乏一个简单的方式将"认知"转化为"行动"。

**痛点：**
- 里程零碎，兑换门槛高，大量沉睡里程
- 碳排放数据抽象，旅客缺乏直观感知
- 绿色出行停留在意识层面，缺少行动闭环

---

## 产品核心体验

**三个步骤，完成一次绿色闭环：**

1. **揭示影响（Reveal）** — 输入航班信息（距离、机型、舱位），系统即时计算本次飞行的碳排放量，并用直觉化比喻呈现（"相当于一棵树 3 个月的吸收量"）
2. **采取行动（Offset）** — 碳排放结果下方直接推荐可兑换的环保商品：共享单车骑行卡、环保酒店券、阿拉善植树公益、航司联名帆布袋。用里程一键兑换，无需跳转
3. **携带证明（Proof）** — 兑换后获得凭证码/二维码/碳抵消证书，可在个人中心查看完整绿色出行记录

---

## 关键功能

| 功能 | 说明 |
|------|------|
| 碳排放计算 | 基于飞行距离 × 机型系数 × 舱位权重的三因子公式，支持 4 种机型、4 种舱位 |
| 绿色商城 | 4 类环保商品：虚拟卡券、碳抵消公益、实体商品，完整浏览-购物车-结算流程 |
| 里程兑换 | 里程余额实时扣减，余额不足时提示差额并推荐可负担商品 |
| 会员控制台 | 里程余额、碳排放统计、兑换订单、绿色出行数据看板 |
| 用户认证 | 邮箱注册/登录，新用户赠送 10,000 里程 |

|------|------|

| 运营管理员 | 管理绿色商品、查看兑换数据（Demo 阶段为 Mock） |

---

## 技术亮点

- **纯前端碳计算** — 无后端依赖，计算逻辑可嵌入任意前端场景
- **Zod 共享校验** — 前后端使用同一套 Schema，类型安全
- **轻量架构** — Next.js + SQLite + Zustand，Demo 级部署零外部依赖
- **AI-Native 开发** — 全流程由 AI Agent 协作完成（PRD → 架构 → UX → 代码）
