# 绿色飞行碳排放计算规则与示例说明

本规范定义了 GreenMiles 系统内部高精度碳排放计算器的核心算法、基础系数矩阵以及计算示例。开发与测试角色需严格按照本规范实现计算逻辑与单元测试。

---

## 1. 核心计算公式

系统在计算单次飞行的二氧化碳排放量时，采用以下公式：

$$\text{单人飞行碳排放量 (kg)} = \text{飞行距离 (km)} \times \text{机型基准排碳系数 (kg/km)} \times \text{舱位分摊权重系数}$$

---

## 2. 基础系数矩阵

### 2.1 机型基准排碳系数表 (Aircraft Base Factors)
*不同机型的发动机效率和载客量不同，单人百公里油耗与排碳存在差异。*

| 机型代码 (Type Code) | 代表机型 | 基准排碳系数 (kg/km) | 备注描述 |
| :--- | :--- | :--- | :--- |
| `NARROW_EFFICIENT` | A320neo / B737MAX | **0.075** | 新型单通道窄体客机，燃油效率高 |
| `NARROW_STANDARD`  | A320 / B737-800 | **0.090** | 经典单通道窄体客机 |
| `WIDE_EFFICIENT`   | B787 / A350 | **0.110** | 新型双通道宽体客机（中长途） |
| `WIDE_LARGE`       | B777 / A380 | **0.140** | 大型/超大型双通道宽体客机 |

### 2.2 舱位分摊权重系数表 (Cabin Multipliers)
*因为头等舱/公务舱物理占地面积大、座椅及配套设备更重，根据国际民航组织（ICAO）标准，其分摊的碳排放权重更高。*

| 舱位代码 (Cabin Code) | 舱位名称 | 权重系数 (Multiplier) | 备注描述 |
| :--- | :--- | :--- | :--- |
| `Y` | 经济舱 (Economy) | **1.0** | 基础分摊权重 |
| `W` | 超级经济舱 (Premium Economy) | **1.5** | 空间稍大 |
| `C` | 公务舱 (Business) | **2.5** | 占用空间和设备较多 |
| `F` | 头等舱 (First) | **4.0** | 占用大量空间与豪华设施 |

---

## 3. 计算示例 (Calculation Examples)

### 示例 1：公务舱（中长途宽体机）
* **场景输入**：
  * **飞行距离**：`1,200` km（如：上海虹桥 $\rightarrow$ 北京首都）
  * **选用机型**：`WIDE_EFFICIENT` (基准系数为 `0.110`)
  * **购买舱位**：`C` 公务舱 (权重系数为 `2.5`)
* **计算过程**：
  $$\text{排碳量} = 1200 \times 0.110 \times 2.5 = 330.0 \text{ kg}$$
* **系统输出**：该行程产生二氧化碳共计 **330.0 kg**。

---

### 示例 2：经济舱（中长途宽体机对比）
* **场景输入**：
  * **飞行距离**：`1,200` km（如：上海虹桥 $\rightarrow$ 北京首都）
  * **选用机型**：`WIDE_EFFICIENT` (基准系数为 `0.110`)
  * **购买舱位**：`Y` 经济舱 (权重系数为 `1.0`)
* **计算过程**：
  $$\text{排碳量} = 1200 \times 0.110 \times 1.0 = 132.0 \text{ kg}$$
* **系统输出**：该行程产生二氧化碳共计 **132.0 kg**。

---

### 示例 3：头等舱（大型宽体机）
* **场景输入**：
  * **飞行距离**：`2,100` km（如：深圳宝安 $\rightarrow$ 北京首都）
  * **选用机型**：`WIDE_LARGE` (基准系数为 `0.140`)
  * **购买舱位**：`F` 头等舱 (权重系数为 `4.0`)
* **计算过程**：
  $$\text{排碳量} = 2100 \times 0.140 \times 4.0 = 1176.0 \text{ kg}$$
* **系统输出**：该行程产生二氧化碳共计 **1176.0 kg**。
